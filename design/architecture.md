# USDY 合约架构设计文档

## 1. 概述

USDY (United States Dollar Yielding) 是 Ondo Finance 的 RWA (Real World Assets) 协议核心代币。本系统允许经过 KYC 验证的用户通过持有 USDY 代币获得美元收益资产的敞口。USDY 是一个非重定基 (non-rebasing) 的 ERC20 代币，价值通过价格增值实现。

## 4. 核心合约详解

### 4.1 RWAHub.sol - RWA 中心合约

**位置**: `contracts/RWAHub.sol`

**类型**: 抽象合约

**职责**:
- 管理 RWA 代币的申购 (Subscription) 和赎回 (Redemption) 流程
- 维护存款和赎回请求的状态映射
- 处理费用计算和收取
- 实现基于角色的访问控制 (RBAC)

**核心数据结构**:
```solidity
struct Depositor {
    address user;              // 存款人地址
    uint256 amountDepositedMinusFees;  // 扣除费用后的存款金额
    uint256 priceId;           // 关联的价格ID
}

struct Redeemer {
    address user;              // 赎回人地址
    uint256 amountRwaTokenBurned;  // 销毁的 RWA 代币数量
    uint256 priceId;           // 关联的价格ID
}
```

**核心函数**:
| 函数 | 访问权限 | 说明 |
|------|----------|------|
| `requestSubscription()` | 公开 | 用户发起申购请求，存入抵押品 |
| `claimMint()` | 公开 | 用户认领铸造的 RWA 代币 |
| `requestRedemption()` | 公开 | 用户发起赎回请求，销毁 RWA 代币 |
| `claimRedemption()` | 公开 | 用户认领赎回的抵押品 |
| `addProof()` | RELAYER_ROLE | 添加链外存款证明 |
| `setPriceIdForDeposits()` | PRICE_ID_SETTER_ROLE | 为存款设置价格ID |
| `setPriceIdForRedemptions()` | PRICE_ID_SETTER_ROLE | 为赎回设置价格ID |

**角色定义**:
| 角色 | 说明 |
|------|------|
| `DEFAULT_ADMIN_ROLE` | 默认管理员 |
| `MANAGER_ADMIN` | 管理管理员，可设置参数 |
| `PAUSER_ADMIN` | 暂停管理员 |
| `PRICE_ID_SETTER_ROLE` | 价格ID设置者 |
| `RELAYER_ROLE` | 中继器，可添加存款证明 |

**位置**: `contracts/RWAHubOffChainRedemptions.sol`

**继承**: `RWAHub`

**职责**:
- 扩展 RWAHub 支持链下赎回功能

**核心函数**:
| 函数 | 说明 |
|------|------|
| `requestRedemptionServicedOffchain()` | 请求链下赎回服务 |
| `pauseOffChainRedemption()` | 暂停链下赎回 |
| `unpauseOffChainRedemption()` | 恢复链下赎回 |
| `setOffChainRedemptionMinimum()` | 设置链下赎回最小金额 |

### 4.3 USDY.sol - USDY 代币合约

**位置**: `contracts/usdy/USDY.sol`

**类型**: 可升级 ERC20 代币

**继承**:
- `ERC20PresetMinterPauserUpgradeable`
- `BlocklistClientUpgradeable`
- `AllowlistClientUpgradeable`
- `SanctionsListClientUpgradeable`

**职责**:
- 实现 USDY ERC20 代币功能
- 在转账时执行合规检查（白名单、黑名单、制裁名单）
- 支持管理员销毁代币

**核心特性**:
- **转账限制**: 每次转账都会检查 from、to 和 msg.sender 的合规状态
- **合约白名单**: 合约地址默认通过白名单检查
- **可升级**: 使用透明升级代理模式

**角色定义**:
| 角色 | 说明 |
|------|------|
| `LIST_CONFIGURER_ROLE` | 可配置名单地址 |
| `BURNER_ROLE` | 可销毁代币 |
| `MINTER_ROLE` | 可铸造代币 |
| `PAUSER_ROLE` | 可暂停转账 |

### 4.4 USDYManager.sol - USDY 管理器

**位置**: `contracts/usdy/USDYManager.sol`

**类型**: 具体合约

**继承**:
- `RWAHubOffChainRedemptions`
- `BlocklistClient`
- `SanctionsListClient`

**职责**:
- 作为 USDY 代币的铸造/赎回入口
- 实现 USDY 特定的合规检查
- 管理可认领时间戳

**核心函数**:
| 函数 | 说明 |
|------|------|
| `setClaimableTimestamp()` | 设置存款可认领的时间戳 |
| `_claimMint()` | 重写父类方法，添加时间戳检查 |
| `_checkRestrictions()` | 实现黑名单和制裁名单检查 |

**特殊机制**:
- **可认领时间戳**: 管理员为每笔存款设置可认领时间，用户必须等待该时间后才能认领

**部署流程**:
```

6. 从工厂撤销所有角色
7. 转移 ProxyAdmin 所有权给 guardian
```

### 5.1 申购流程 (Subscription)


## 8. 安全特性

### 8.1 重入保护
- 使用 OpenZeppelin 的 `ReentrancyGuard`
- 所有资金操作函数都标记为 `nonReentrant`

### 8.2 暂停机制
- 可独立暂停申购和赎回
- 可暂停链下赎回
- 只有 `PAUSER_ADMIN` 可暂停，`MANAGER_ADMIN` 可恢复

### 8.3 价格安全
- 最小价格更新间隔 (23小时)
- 最大单次价格变化限制
- 与 Chainlink 预言机对比验证

### 8.4 合规控制
- 三层合规检查: 白名单 + 黑名单 + 制裁名单
- 转账时检查 from、to 和 msg.sender
- 合约地址默认通过白名单

### 8.5 可升级性
- USDY 代币使用透明升级代理
- Allowlist 支持升级
- Blocklist 不可升级 (设计决策)

## 11. 总结

USDY 系统是一个完整的 RWA 代币化解决方案，具有以下特点:

1. **模块化设计**: 核心业务、定价、合规等功能分离
2. **安全优先**: 多层安全检查、价格验证、重入保护
3. **合规友好**: 支持白名单、黑名单、制裁名单检查
4. **可升级性**: 关键组件支持升级，适应未来需求
5. **灵活赎回**: 支持链上和链下赎回方式
6. **透明定价**: 基于预言机的价格机制，可验证

整个系统围绕 RWAHub 抽象合约构建，通过继承和组合实现不同 RWA 代币的业务逻辑。
